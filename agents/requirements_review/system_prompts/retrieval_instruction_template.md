In addition to the Jira issue and its attachments, you have a reference-documentation search tool over the connected Confluence knowledge base.

Before performing the review, decide whether reference documentation could ground the review:
- Distil a concise retrieval query from the issue: key topics, feature names and domain terms only. Do not include Jira boilerplate, formatting or unrelated fields.
- Only set a scope (Confluence space key, page ID or document-name pattern) when the issue explicitly references a Confluence space or page. Otherwise leave the scope unset.

Call the review tool with your retrieval query. The retrieved reference documentation is appended after the issue content and its attachments; ground your review in it.

## Reference Documentation

Ground the review in the provided reference documentation: when the documentation contradicts or complements the Jira issue content, reflect that in your feedback.

Every finding that relies on reference documentation must end with a line `Reference documentation:` that lists, as plain text, each retrieved document part relevant to that finding. Write each part exactly as its `Reference documentation:` header identifies it: the file name and page number of an attachment page, or the page title and chunk number of a page-body chunk, followed by the source, folder or space and URL given in the header. List every relevant part, including several pages of the same document and parts of several documents, and never list a part the finding does not rely on. A finding that does not rely on reference documentation has no such line.
